# 🌍 Applied AI Lab – Learning Journey

Welcome to my Applied AI Lab repository! This space documents my personal reflections and takeaways as I progress through the lab's end-to-end computer vision projects.

---

## 🚀 Lab Overview

The Applied AI Lab is a project-based program focused on solving real-world computer vision problems using deep learning, PyTorch, and Transformers. The lab emphasizes hands-on skills across all stages of the ML pipeline — from data preparation to model deployment.

### 🔍 Projects Across the Globe

1. **Wildlife Conservation (Côte d'Ivoire)** – Animal tracking using camera trap images  
2. **Crop Disease Detection (Uganda)** – Classifying plant diseases  
3. **Traffic Monitoring (Bangladesh)** – Object detection for urban traffic  
4. **Face Recognition (India)** – Detection and recognition in video interviews  
5. **Medical Imaging (Spain)** – Generating synthetic medical images  
6. **Social Media Analytics (USA)** – Computer vision for marketing insights


---

## 🧠 What I’m Learning

- Deep learning fundamentals with PyTorch
- Image classification, object detection & generative models
- Ethical AI and environmental considerations
- Self-directed debugging and learning techniques
- Real-world AI applications with a global perspective
